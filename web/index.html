What can generate charges?

While running: EC2 compute, public IPv4, possible CPU surplus credits, and internet data transfer. While stopped: the 8 GB EBS disk remains billed. The controller also uses CloudFront, S3, API Gateway, Lambda, Cognito, and CloudWatch logs; usage and account free-tier eligibility affect charges.

The daily reporter queries Cost Explorer only once a day, plus additional pages if needed. Each billing query page costs $0.01. Report storage and execution also have usage charges. Some fees and services cannot be attributed by tag.
